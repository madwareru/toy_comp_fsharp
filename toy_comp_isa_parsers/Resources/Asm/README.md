## Assembly files collection

### What is included
This is the collection of test assembly files for next programs:
- **fact** prints a factorial of a number five
- **fib** prints a tenth number if Fibonacci sequence
- **sierpinski** prints a Sierpinski triangle factorial
- **carpet** prints a Sierpinski carpet factorial
- **mandelbrot** prints a Mandelbrot fractal

### File extensions explained
There are three different file extensions:
- **.asmm** for an assembly file in a memory-to-memory ISA
- **.asms** for an assembly file in a stack ISA
- **.asmr** for an assembly file in a register ISA
